Italy - Regions

Adds the 20 Italian administrative regions as selectable states for Italy

Overview

Odoo's base localization ships the Italian provinces (Milano, Roma, Torino, etc.) as states for Italy. This module adds the 20 regions (Piemonte, Lombardia, Lazio, Sicilia, etc.) as additional state records, using the official ISO 3166-2:IT region codes (IT-01 through IT-20).

Features

  • All 20 Italian regions added as res.country.state records
  • Official ISO 3166-2:IT codes (IT-01 – IT-20)
  • Pure data module — no Python logic, no dependencies beyond base
  • Safe to install alongside the existing Italian provinces
  • Records are noupdate, so users can freely edit or remove them without module upgrades overwriting changes

Note

After installing this module, the State field for Italian addresses will list both provinces and regions together. Choose the level of detail appropriate to your use case (e.g. reporting or grouping by region vs. precise province-level addressing).
