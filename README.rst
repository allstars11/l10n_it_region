Italy - Regions
===============

Adds the 20 Italian administrative regions as ``res.country.state``
records for Italy, using the ISO 3166-2:IT region codes (IT-01 – IT-20).

Odoo's base localization already ships the Italian **provinces**
(Milano, Roma, Torino, etc.) as states. This module adds the coarser
**regions** (Piemonte, Lombardia, Lazio, etc.) as additional records —
both sets coexist.

Installation
------------
No external dependencies. Just install like any other Odoo app.

Configuration
-------------
Nothing to configure. Records are loaded as data with ``noupdate="1"``.
